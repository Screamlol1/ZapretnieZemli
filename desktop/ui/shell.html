Отчёт для разбора неполадок

Сохраните техническую сводку, если игра не запускается, не подключается или работает неправильно.

В JSON-файл войдут
  • Версии приложения, Electron, Node.js и комплектных компонентов, включая Python.
  • Версия Windows, архитектура и параметры окна.
  • Состояние своего сервера, локальная проверка его доступности и безопасные категории недавних ошибок.

Пароли, cookies, аккаунты, кампании, базы данных, адреса приглашений, домашние пути и исходные журналы в отчёт не включаются. Сервер для проверки не запускается.

Вы выберете папку. Файл останется на вашем компьютере; автоматической отправки нет. Перед передачей разработчику его можно открыть в текстовом редакторе.
