# Запретные Земли для Windows

Устанавливаемая версия для **Windows 10/11, 64-разрядная x64**. Игра работает в едином окне; всё необходимое для запуска сервера включено в установщик. Отдельно устанавливать Python или Node.js игрокам не нужно.

## Установка и первый запуск

1. Запустите `outputs/windows/ZapretnieZemli-Setup-1.2.0-x64.exe`.
2. Выберите папку установки. Программа устанавливается для текущего пользователя и создаёт ярлык «Запретные Земли».
3. Откройте игру с ярлыка и выберите нужный вариант.

**«Моя игра на этом компьютере»** запускает ваш сервер. Зарегистрируйте аккаунт, сохраните код восстановления пароля и создайте кампанию или героя в личном кабинете. Подтверждённые действия сохраняются автоматически.

**«Подключиться к игре»** открывает существующий сервер по ссылке Мастера. Это подходит и для продолжения прежней кампании, которая уже работает в браузере.

Аккаунты и персонажи принадлежат конкретному серверу. Новая установка начинает с пустой локальной базы; сохранения прежнего веб-сервера автоматически не переносятся. Для доступа к ним подключитесь к прежнему адресу и войдите в свой аккаунт на нём.

## Единое окно и настройки

Кабинет, кампания, редакторы и тренировочный бой открываются внутри одного окна. Верхняя панель остаётся доступна: «Подключения», назад/вперёд, обновление и настройки. Кнопка «Вернуться в игру» возвращает к открытой странице, сохраняя незаконченный редактор. Переход к подключениям не останавливает ваш сервер.

В **«Настройки» → «Экран»** доступны оконный режим, полный экран и окно без рамки по размеру монитора. Размер в пикселях выбирается для оконного режима; полный экран и окно без рамки используют текущий монитор. Масштаб интерфейса: 75–150%. После смены режима или размера подтвердите результат в течение 15 секунд, иначе прежний вид вернётся автоматически.

Во вкладке «Поведение» можно включить запоминание положения и размера окна и предупреждение перед закрытием своего сервера. Несохранённый лист защищён отдельным подтверждением независимо от настройки предупреждения сервера.

Клавиши: **F11 / Alt+Enter** — полный экран; **Ctrl+,** — настройки приложения; **Alt+← / Alt+→** — история; **Ctrl+R** — обновление; **Ctrl+плюс / минус / 0** — масштаб. Переключение экранного режима не перезапускает сервер.

В самой игре кнопка «Настройки» меняет размер текста, плотность, контраст, анимации и звук. Эти параметры доступны также в браузере, сохраняются на устройстве и не влияют на интерфейс других игроков. Тематические загрузочные экраны показываются только во время реальной загрузки, без искусственной задержки.

## Совместная игра

Мастер и десять игроков могут свободно смешивать оба варианта. Главное — подключиться к **одному серверу и одной кампании**.

1. Мастер запускает свою игру и нажимает **«Пригласить через интернет»** в домашнем окне приложения.
2. После появления общей HTTPS-ссылки копирует её. Внутри кампании открывает меню «Кампания и доступ» и берёт код и ключ приглашения для игроков.
3. Отправляет участникам ссылку, код и ключ.
4. Игроки открывают ссылку в браузере либо вставляют её в поле «Подключиться к игре» установленной версии. Затем входят или регистрируются на этом сервере и присоединяются к кампании.

Адрес `http://127.0.0.1:…` работает только на компьютере, где запущена игра. Для других участников используйте общую HTTPS-ссылку.

Общая ссылка временная: она действует, пока приложение Мастера, его компьютер и интернет-соединение работают. После повторного включения общего доступа адрес может измениться; аккаунты и кампании сохранятся. Кнопка **«Выключить общий доступ»** отключает внешние подключения, сохраняя локальную игру. Закрытие приложения останавливает его локальный сервер; чужой сервер, к которому вы подключались, продолжает работать.

## Сохранения и резервные копии

По умолчанию данные расположены отдельно от программы:

- `%LOCALAPPDATA%\ZapretnieZemli\data` — база кампаний, аккаунты, загруженные карты и журналы.
- `%LOCALAPPDATA%\ZapretnieZemli\profile` — профиль окна приложения: входы и настройки браузерной части.

В домашнем окне раскройте **«Сохранения и резервные копии»**. Кнопка **«Открыть папку сохранений»** покажет фактическую папку. Кнопка **«Создать резервную копию…»** предложит выбрать место и сделает согласованную копию базы и карт. Перед переносом данных на другой компьютер используйте эту копию; не заменяйте работающую базу вручную.

Обновление программы сохраняет эти папки. Удаление приложения также не удаляет игровые данные.

## Диагностика для сообщения об ошибке

Откройте **«Настройки» → «Диагностика» → «Сохранить диагностику»** и выберите место для JSON-файла. Перед сохранением интерфейс перечисляет его содержимое. Отчёт остаётся локально: приложение никуда его не отправляет. При необходимости откройте файл в текстовом редакторе и приложите к описанию ошибки самостоятельно.

В отчёте есть версии приложения, Electron и Node.js, версии комплектных Python, Node.js и cloudflared из манифеста сборки с отметкой наличия компонентов, версия ОС, архитектура, параметры окна, состояние локального сервера и ограниченный список категорий недавних ошибок. Проверка доступности обращается только к уже работающему своему серверу; она не запускает сервер, не подключается к внешним приглашениям и не перезапускает игру.

В отчёт не входят базы данных, аккаунты, пароли, cookies, ключи и содержимое кампаний, URL приглашений, домашние пути, исходные сообщения ошибок и журналы. Диагностика помогает разобрать неполадку; для переноса игровых данных используйте резервную копию отдельно.

## Сборка из исходников

На компьютере разработчика нужны Node.js 22.12 или новее с npm, Windows x64 и интернет для загрузки зависимостей. Из папки проекта, содержащей `server.py`, выполните:

```powershell
cd desktop
npm ci
npm run prepare:runtime
npm run dist
```

`prepare:runtime` загружает закреплённые версии Python, Node.js и cloudflared и проверяет их контрольные суммы. `dist` собирает чистые ресурсы игры, приложение Electron и установщик NSIS в `outputs/windows`. Рабочие аккаунты, кампании, локальные официальные карты и книги в установщик не входят. Версии и лицензии компонентов указаны в `runtime-lock.json` и `THIRD-PARTY.md`.

Текущая сборка **не подписана сертификатом издателя**: Windows может показывать предупреждение о неизвестном издателе. Для выпуска с подписью требуется отдельный сертификат и настройка подписания.
