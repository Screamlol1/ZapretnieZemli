# Совместный тест через интернет

Игра использует Python-сервер, SQLite и Node.js. GitHub Pages обслуживает только статические файлы и не подходит для общей кампании.

## Временная HTTPS-ссылка

Для первого совместного теста используется [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/). Учётная запись и собственный домен не требуются. Ссылка действует, пока работают компьютер, сервер и туннель; после нового запуска адрес меняется. Это тестовое размещение без гарантии постоянной доступности.

Установите Python 3.11+, Node.js 20+ и скачайте Windows x64 `cloudflared.exe` с [официальной страницы Cloudflare](https://developers.cloudflare.com/tunnel/downloads/). Из каталога игры запустите:

```powershell
.\start-public-test.ps1 -Cloudflared 'C:\путь\cloudflared.exe'
```

Скрипт запускает процессы в фоне, проверяет доступность игры по HTTPS, выводит ссылку `https://…trycloudflare.com` и использует отдельную базу `.runtime/test.sqlite`. По умолчанию локальный порт — 8789; `-Port 8790` выбирает другой свободный порт. Основной сервер на 8787/8788 продолжает работать отдельно. Данные тестовой базы сохраняются между запусками. Cloudflare автоматически выбирает протокол; если сеть блокирует HTTP/2, укажите `-Protocol quic`. Подключению может потребоваться около минуты на диагностику и появление DNS. Если HTTPS-проверка не проходит, скрипт завершает созданные процессы и сообщает ошибку вместо выдачи неработающей ссылки.

1. Мастер открывает HTTPS-ссылку, создаёт кампанию и сохраняет её код и ключ Мастера.
2. В меню «Пригласить игроков» скопируйте **код и ключ для игроков**.
3. Отправьте участникам HTTPS-ссылку, код и ключ для игроков. Они указывают имя и нажимают «Присоединиться». Ключ Мастера передаётся только человеку, который ведёт игру.
4. Каждый игрок создаёт героя в разделе «Персонажи»; Мастер собирает отряд на странице карты. Одна кампания вмещает Мастера и десять игроков.

Остановить общий доступ:

```powershell
.\stop-public-test.ps1
```

Скрипт проверяет записанные процессы и завершает только этот запуск. База кампаний остаётся в `.runtime/test.sqlite`. Журналы находятся в `.runtime/server-errors.log` и `.runtime/tunnel.log`. Каталог `.runtime` не входит в GitHub и исходный архив.

Тестовый режим ограничивает запросы на адрес: 30 входов/созданий кампаний, 240 изменений и 1800 чтений за минуту. Лимит чтения допускает общий внешний адрес группы с 11 участниками. Переполнение возвращает 429 и `Retry-After`. Сервер допускает до 50 тестовых кампаний; файлы базы, исходники и локальные изображения не доступны как статические URL. Карта выдаётся только вошедшим участникам. Заголовок Cloudflare с адресом посетителя используется только при явном `--public-test` и подключении прокси с loopback; этот режим предназначен для сервера, привязанного к `127.0.0.1`, за туннелем.

Ручной запуск сервера:

```powershell
python server.py --host 127.0.0.1 --port 8789 --database .runtime/test.sqlite --public-test
```

## Постоянное размещение

Нужен хостинг с Python 3.11+, Node.js 20+, постоянно работающим процессом и диском для SQLite/загруженных карт. Настройте HTTPS-прокси, резервное копирование базы и управление доступом к созданию кампаний. Доступность существующей локальной тестовой ссылки зависит от компьютера; она не заменяет такое размещение.
