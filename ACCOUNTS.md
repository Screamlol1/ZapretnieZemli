# Личный кабинет

Главная страница `/` открывает кабинет. Прежний игровой стол находится на `/index.html`.

## Первый вход и кампании

1. Выберите «Регистрация». Логин: 3–32 латинские буквы, цифры, `.`, `-`, `_`; регистр не учитывается. Пароль: 15–128 символов, можно использовать фразу. Имя за столом отделено от логина.
2. Скачайте код восстановления. Он показывается при регистрации, смене и восстановлении пароля; новый код заменяет старый. Почтовой рассылки нет.
3. Создайте кампанию как Мастер или введите код и ключ приглашения. Кампания появится в «Моих кампаниях». В дальнейшем достаточно кнопки «Подключиться» / «Продолжить как Мастер», в том числе на другом устройстве.
4. Из игрового стола вернитесь кнопкой «Личный кабинет». Она освобождает место в кампании, сохраняя вход в аккаунт. «Выйти из аккаунта» закрывает текущий вход; связанные с ним игровые токены перестают работать.

Если играли раньше, зарегистрируйтесь **в том же браузере и по тому же адресу сервера**, откройте «Привязать прежние кампании». Сохранённый секрет восстановления подтверждает владение прежним участником. По совпадению имени аккаунты не объединяются. На другом устройстве можно войти по приглашению; для прежнего героя может понадобиться назначение владельца Мастером. После привязки прежний секрет сам по себе больше не даёт доступ без входа в аккаунт. Кампанию с привязанным Мастером продолжает только его аккаунт.

## До десяти личных персонажей

- «Мои персонажи» → «Создать персонажа» → заполнить лист → **«Сохранить в личный кабинет»**. Для импорта внутри редактора есть открытие JSON.
- «Открыть лист» показывает характеристики, текущее состояние связанного героя, предметы и заметки. Полный редактор доступен отдельной кнопкой.
- «Добавить моего героя» на карточке кампании переносит свободный личный лист в неё. Новый герой начинает со стартовым состоянием и снаряжением по правилам.
- Уже существующего героя можно сохранить из списка «Мои герои в этой кампании» или кнопкой «Сохранить в кабинет» на игровом столе. Доступны только свои игровые персонажи.
- Связанный лист автоматически обновляется при сохранении действий кампании: ранения, сила воли, припасы, внешний вид, экипировка, предметы. Для просмотра свежего состояния в уже открытом кабинете нажмите «Обновить».
- Редактирование связанного листа изменяет тот же лист в кампании. Инвентарь и ранения сохраняются. Во время боя или выполнения дорожного занятия действуют существующие запреты редактора. Устаревшая версия отклоняется, чтобы другая вкладка не перезаписала изменения.
- Один личный лист связан с одним героем одной кампании. «Копия» создаёт отдельный стартовый лист без добычи и текущего состояния. Повторное добавление того же листа не дублирует героя.
- «Скачать» выдаёт JSON исходного листа, совместимый с конструктором. В окне просмотра «Скачать полное сохранение» выдаёт также текущее состояние и предметы. Эта полная копия предназначена для архива; независимый откат героя не разрешён, чтобы не дублировать предметы.
- «Удалить из кабинета» освобождает место; герой в кампании остаётся. Если Мастер удалил героя или передал другому владельцу, в прежнем кабинете остаётся последняя личная копия, дальнейшие изменения чужого героя не поступают.

Ограничение в 10 записей проверяется сервером. Можно редактировать и скачивать уже сохранённые листы при заполненном кабинете. Ограничения кампании остаются прежними: один Мастер, десять игроков, до пяти героев одного игрока. Редактор использует текущие правила создания; полноценное развитие за опыт ещё не реализовано.

## Хранение и доступ

Аккаунты, личные листы и привязки находятся **в той же SQLite-базе**, что и кампании. Резервное копирование базы сохраняет всё вместе. Сервер выдаёт только содержимое текущего аккаунта; секреты Мастера в личные копии игроков не включаются. Контрольные сохранения кампании не содержат аккаунтов, хешей паролей, cookie и приглашений; откат кампании сохраняет текущие привязки.

Пароли: PBKDF2-HMAC-SHA256, 600 000 итераций, случайная индивидуальная соль; параметры соответствуют [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html). Секреты входа и коды восстановления хранятся в базе в виде SHA-256-хешей. Cookie имеет HttpOnly, SameSite=Strict, срок 30 дней, Secure на внешнем адресе. Для localhost разрешён HTTP; **для входа по LAN/интернет-адресу нужен HTTPS**. Смена/восстановление пароля отзывают другие входы.

Входы ограничены по адресу; после десяти неверных паролей или кодов восстановления аккаунт блокируется на 15 минут. JSON API проверяет Origin и Sec-Fetch-Site. В тестовом режиме сохраняется предел 50 кампаний.

При смене адреса временного туннеля потребуется войти заново, но аккаунт и кабинет останутся в базе. Данные одного запуска сервера не появляются автоматически в другом сервере с другой SQLite-базой. Для постоянной игры всё ещё нужен постоянный сервер, HTTPS-адрес и резервное копирование; временный туннель не заменяет хостинг.
