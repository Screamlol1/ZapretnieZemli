# Графические ресурсы

`public/tools/assets/battle-atlas.png` и `battle-extra.png` перенесены из ранее созданной боевой песочницы. Они созданы встроенным ImageGen для этого проекта; это авторские сгенерированные игровые атласы, а не иллюстрации из книг Free League. Первый атлас содержит 4×4 ячейки, дополнительный — 3×2. Спрайты используются в локальной боевой песочнице.

Полные книги, официальные карты, PDF и материалы из исследовательской рабочей папки не включены в репозиторий. Для правил используются числовые данные, названия и краткие пояснения конструктора. Ссылки на первоисточники приведены в README.
