# Графические ресурсы

Пергаментная сетка и знаки местности в `public/world-map.js` — собственная SVG-графика проекта. Фон из официальной региональной карты Запретных Земель устанавливается только локально в `local-assets/`; карты пользователей сохраняются в `map-images/`. Эти папки исключены из GitHub и исходного архива. Географические данные официальной региональной карты в код не включены.

`public/tools/assets/battle-atlas.png` и `battle-extra.png` перенесены из ранее созданной боевой песочницы. Они созданы встроенным ImageGen для этого проекта; это авторские сгенерированные игровые атласы, а не иллюстрации из книг Free League. Первый атлас содержит 4×4 ячейки, дополнительный — 3×2. Спрайты используются в локальной боевой песочнице.

Полные книги, официальные карты, PDF и материалы из исследовательской рабочей папки не включены в репозиторий. Для правил используются числовые данные, названия и краткие пояснения конструктора. Ссылки на первоисточники приведены в README.

## Модели v2

`characters-v2.png`, `kins-v2.png`, `monsters-v2.png` созданы встроенным ImageGen с предыдущим атласом как стилистическим образцом. Все три атласа — регулярные сетки 4×4 на прозрачном фоне. Строки: стояние, шаг, удар, колдовство/особая способность. Человеческие силуэты, дварф, эльф; полурослик, полуволк, орк, гоблин; четыре собственных чудовища. Полуэльф использует эльфийскую основу. Разрешение клетки определяется от фактического размера картинки; модель рисуется с одинаковым масштабом по обеим осям.

Промпты и решения по стилю сохранены в ART-DIRECTION.md. Перекраска выполняется в браузере при отображении; исходная прозрачность и пропорции атласов сохраняются. Короткие анимации используют готовые позы и переходы, не являются полными направленными циклами.
