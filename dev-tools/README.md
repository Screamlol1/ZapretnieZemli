# Локальный поиск по правилам

Инструмент разработчика ищет по тексту PDF и возвращает название источника, группу, **номер страницы PDF** и короткий фрагмент. Номер может отличаться от напечатанного в книге. Источники и индекс остаются на компьютере; в игру, установщик и GitHub они не входят.

В отдельной среде Python установите `pip install -r dev-tools/requirements.txt`. Зависимость `pypdf` нужна только для добавления книг. Сам поиск работает на стандартном Python с SQLite FTS5.

Из корня репозитория:

```powershell
python dev-tools/rules_index.py add "путь/Player-Handbook.pdf" --title "Книга игрока" --group official
python dev-tools/rules_index.py add "путь/Errata.pdf" --title "Исправления" --group errata
python dev-tools/rules_index.py list
python dev-tools/rules_index.py search "инициатива" --group official
python dev-tools/rules_index.py search "opposed roll" --group official --limit 5
```

Группы `official`, `errata`, `reforged`, `house` задаются явно при добавлении. По умолчанию поиск показывает все группы с подписями; для проверки основной механики используйте `--group official` и отдельно сверяйте `errata`. Найденное в Reforged не становится автоматически правилом игры.

Есть русские синонимы для нескольких английских терминов: «инициатива», «пойти на риск», «встречная проверка», «путешествие», «воля», «магия», «цитадель», состояния. Остальные запросы вводите на языке книги. Все слова запроса обязательны, поддерживается поиск по началу слова; операторы SQL/FTS не выполняются.

Индекс по умолчанию: `.cache/rules-index.sqlite`. Для другого расположения укажите `--database путь` **перед** командой. Повторный импорт неизменной книги пропускается по SHA256; изменённая книга заменяет свои старые страницы в одной транзакции. PDF без текстового слоя требует предварительного OCR; защищённые паролем PDF не поддерживаются. Это поиск источников для разработки, а не автоматическое толкование правил.
