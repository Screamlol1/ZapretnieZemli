# Запретные Земли — общий игровой стол

Рабочая первая версия веб-приложения для **одного Мастера и десяти игроков**. Интерфейс на русском языке. Python обслуживает кампании и проверяет права; браузер отображает карту. Кампании сохраняются в SQLite. Установка npm-пакетов не требуется.

## Запуск

Установите Python 3.11+ и Node.js 20+. Из папки проекта:

```powershell
python server.py
```

Откройте http://127.0.0.1:8787. Создайте кампанию, сохраните код и ключ Мастера, передайте игрокам код и отдельный ключ приглашения.

Для подключения из локальной сети:

```powershell
python server.py --host 0.0.0.0 --port 8787
```

Игроки открывают `http://АДРЕС_КОМПЬЮТЕРА:8787`. Для игры через интернет нужен сервер с Python и Node.js и HTTPS reverse proxy. GitHub хранит исходники; GitHub Pages не запускает этот сервер. Интернет-развёртывание пока не настроено.

## Что работает

- Кампании и отдельные секретные приглашения для Мастера и игроков.
- До 11 активных подключений; один Мастер. Неактивное подключение освобождает место через 45 секунд.
- Конструктор на основе ранее созданных правил: народы, профессии, возраста, навыки, достоинства, снаряжение, случайные предыстории. Кнопка «В кампанию» появляется при открытии из игрового стола.
- Импорт листов JSON с повторной проверкой на сервере. Игрок редактирует только свои листы; Мастер имеет доступ ко всем. Листы других игроков доступны как имя, без тайны и заметок.
- Создание скрытых персонажей ведущего через конструктор и импорт.
- Две общие сетки 24×16: карта путешествия и поле сражения. Восемь типов местности, скрытые клетки, размещение и перемещение именованных жетонов.
- Скрытые клетки, жетоны и персонажи не отправляются игрокам.
- Общий журнал, сообщения, серверные броски трёх пулов с отрицательными модификаторами навыка.
- Генератор шести авторских зацепок случайных событий. Это не полная официальная таблица встреч.
- Предыдущая боевая песочница сохранена как отдельный локальный инструмент.
- Сохранение кампании при перезапуске; восстановление владельца листов при входе с того же браузера. Для другого браузера перенос владельца пока не предусмотрен.

## Границы первой версии и следующие этапы

Это ещё не полная реализация всех правил ЗЗ. Общая карта пока не связана с боевым движком. Онлайн-форсирование, автоматический урон, инициатива, все достоинства и школы магии, критические травмы, путешествия, припасы и цитадель требуют дальнейшей реализации. Перенесённая песочница содержит собственные гексовые допущения и частичную магию; её ограничения описаны в её интерфейсе.

Листы сохраняются как черновики; непотраченные очки допустимы. Рост персонажа после создания, назначения владельца Мастером, редактирование существующего листа прямо в кампании, загрузка фоновых изображений карты, масштабирование, измерение расстояния, массовое рисование и многоуровневый туман войны пока отсутствуют.

Reforged в общей кампании выключен до согласования модулей. В автономном конструкторе прежние переключатели сохранены для сравнения; сервер отклоняет импорт листов с включёнными модулями.

Для эксплуатации через интернет нужны ограничения частоты запросов, управление учётными записями и восстановлением доступа, резервные копии и настройка HTTPS. Сессионные ключи действуют до перезапуска сервера; повторный вход осуществляется ключом кампании. Не публикуйте `campaigns.sqlite`: она содержит приглашения и частные данные.

## Проверки

```powershell
node rules-tests/all.mjs
python -m unittest discover -s tests -v
```

Наследуемые проверки покрывают создание, предыстории, возрастные переходы, Reforged и боевую песочницу. Новые серверные проверки покрывают 11 подключений, права, скрытые данные, проверку листов, владение и перезапуск.
